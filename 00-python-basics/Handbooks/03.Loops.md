### 1. Core Mechanics: `while` Loops

* **Concept:** A `while` loop repeatedly executes a block of code *as long as* a specified boolean condition evaluates to `True`.
* **Anatomy:**
```python
i = 3
while i > 0:
    print("meow")
    i -= 1  # Crucial: Decrement prevents infinite loops

```


* **Important Point (Infinite Loops):** If the condition never becomes `False`, your program will hang forever. Always ensure your loop variable is updated or that a break condition exists.
* **Pro-Tip (The `while True` + `break` Pattern):** Often in Python, you want a loop to run at least once. Instead of duplicate validation checks, professional developers use an infinite loop paired with a conditional `break`:
```python
while True:
    n = int(input("What's n? "))
    if n > 0:
        break

```

### 2. Core Mechanics: `for` Loops & Iterables

* **Concept:** A `for` loop iterates over a sequence (like a list, string, or range) rather than evaluating a dynamic boolean condition.
* **Anatomy:**
```python
for i in [0, 1, 2]:
    print("meow")

```


* **The `range()` Function Shortcut:** Typing out lists for large iterations is inefficient. `range(n)` generates a sequence of numbers from `0` up to (but not including) `n`.
* `range(3)` produces `0, 1, 2`.
* `range(1, 4)` produces `1, 2, 3` (start, stop, step).


* **Pro-Tip (The Underscore `_` Variable):** If your loop variable (like `i`) is never actually used inside the loop body, Python convention dictates naming it an underscore `_` to signal to other developers that the variable is intentionally ignored:
```python
for _ in range(3):
    print("meow")

```

### 3. Advanced Loop Control Keywords

* **`break`**: Immediately terminates the current loop entirely, jumping execution to the first line of code *after* the loop block.
* **`continue`**: Skips the rest of the current iteration and forces the loop to jump straight to the next cycle's condition check.
* **`else` Clause with Loops (Python Secret):** Python has a unique feature where a `for` or `while` loop can have an `else` block. It executes *only* if the loop finished normally without encountering a `break` statement.

### 4. Data Structures Intro: Lists (`list`)

* **Concept:** A mutable, ordered collection of items enclosed in square brackets `[]`.
* **Iteration Pattern:**
```python
students = ["Harry", "Ron", "Hermione"]
for student in students:
    print(student)

```


* **Pro-Tip (`len()` + `range()` vs Direct Iteration):** Beginners often write `for i in range(len(students)): print(students[i])`. Senior Python style prefers direct iteration (`for student in students:`) unless you explicitly need the index tracker. If you *do* need both index and value, use Python's built-in `enumerate()`:
```python
for i, student in enumerate(students):
    print(i + 1, student)

```



---

### 5. Dictionaries (`dict`) & Nested Data

* **Concept:** Key-value data stores enclosed in curly braces `{}`.
* **Iterating over Dictionaries:**
```python
students = {"Hermione": "Gryffindor", "Harry": "Gryffindor", "Draco": "Slytherin"}

# Loops through keys by default
for student in students:
    print(student, students[student], sep=", ")

# Professional way using .items()
for student, house in students.items():
    print(f"{student} is in {house}")

```
